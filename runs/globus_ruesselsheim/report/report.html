Method

  • Data: Sentinel-1 IW GRD-HD scenes read directly from the public AWS archive (s3://sentinel-s1-l1c); only a small window around the site is downloaded from each cloud-optimised GeoTIFF.
  • Radiometry: σ⁰ calibration with the product LUT, thermal noise removed (range × azimuth noise LUT).
  • Geometry: lon/lat/height → line/pixel fitted to the nearest geolocation tie points (mean residual 0.52 px), site mapped at 135 m ellipsoidal height, bilinear resampling onto a 10 m UTM grid.
  • Activity: per scene, the median VH σ⁰ over the lot. Its excess over the track's empty baseline (10th percentile of that track's series) removes the effect of viewing geometry. The activity index is the excess scaled so that 0 = empty baseline and 100 = the 95th percentile of all scenes (1.57 dB). VH (cross-polarised) is used by default because cars produce multiple-bounce, depolarised echoes while wet or frozen ground changes mainly the co-polarised channel.
  • Maps: per pixel, a scene counts as "occupied" if the 5×5 speckle-filtered σ⁰ is ≥3 dB above that pixel's empty baseline.

Caveats

  • Sentinel-1 only sees the site around 06–07 h and 18–19 h local time. This is a sample of activity at those times, not a daily total.
  • The index is relative: a fixed number of cars does not always give the same index, because it depends on car type, layout and wetness. Calibrate it against counts if absolute numbers are needed.
  • Tracks with fewer than 8 scenes have an unreliable baseline (flagged low_confidence in the CSV).
  • Snow, standing water and construction change the empty-lot backscatter, so check unusual acquisitions against these causes.
